# Netra — карта сети организации

Статический редактор сети на HTML, CSS, JavaScript и SVG, без зависимостей для запуска.

Возможности: несколько карт, устройства и соединения, редактирование IP/VLAN/модели/статуса/заметок, цветные зоны, перетаскивание, масштабирование, поиск и фильтры, таблица оборудования, представление VLAN, отмена и повтор действий. Экспорт JSON/SVG/CSV, импорт JSON.

Данные автоматически сохраняются в localStorage этого браузера. Для резервного копирования и переноса используйте JSON. Карта при первом запуске демонстрационная. Статусы назначаются вручную: приложение не сканирует сеть и не проверяет оборудование.

Исходные файлы сайта находятся в `dist/`. Разместите их на любом статическом веб-сервере. Настройки Sites: `.openai/hosting.json`.

`npm test` проверяет импорт, целостность связей, удаление устройств и IPv4. Для работы сайта установка пакетов и сборка не требуются.

Горячие клавиши: V — выбор, H — перемещение, C — соединение, / — поиск, Ctrl/⌘+Z — отмена, Ctrl/⌘+Shift+Z — повтор, 0 — показать всю карту. Справка доступна в боковой панели.
