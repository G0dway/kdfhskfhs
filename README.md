# Netra — карта сети организации

Статический редактор сети на HTML, CSS, JavaScript и SVG, без зависимостей для запуска.

Возможности: несколько карт, устройства и соединения, редактирование IP/VLAN/модели/статуса/заметок, цветные зоны, перетаскивание, масштабирование, поиск и фильтры, таблица оборудования, представление VLAN, отмена и повтор действий. Экспорт JSON/SVG/CSV, импорт JSON.

Данные автоматически сохраняются в localStorage этого браузера. Для резервного копирования и переноса используйте JSON. Карта при первом запуске демонстрационная. Статусы назначаются вручную: приложение не сканирует сеть и не проверяет оборудование.

## Запуск без сервера

Скачайте `dist/index.html` и откройте его двойным щелчком в современном браузере. Этот HTML-файл самодостаточен: весь код и стили включены внутрь, поэтому кнопки и редактор работают при открытии с диска и без интернета. Сетевые шрифты необязательны: без интернета используются системные.

Можно также скачать ZIP репозитория через Code → Download ZIP, распаковать его и открыть `dist/index.html`. Для размещения в интернете достаточно загрузить этот файл на статический веб-сервер. Настройки Sites: `.openai/hosting.json`.

## Разработка и проверка

Исходный шаблон страницы — `src/index.html`, стили — `dist/style.css`, логика — `dist/app.mjs` и `dist/model.mjs`. После правок запустите `npm run build`: команда заново соберёт самодостаточный `dist/index.html`. Сборка использует только встроенные средства Node.js.

Для автоматических проверок выполните `npm ci`, затем `npm test`. Тесты проверяют импорт, целостность связей, удаление устройств, IPv4 и работу кнопок из готового HTML-файла в модели DOM. Реальный браузер эти тесты не заменяют. Для использования готового сайта установка пакетов и сборка не нужны.

Горячие клавиши: V — выбор, H — перемещение, C — соединение, / — поиск, Ctrl/⌘+Z — отмена, Ctrl/⌘+Shift+Z — повтор, 0 — показать всю карту. Справка доступна в боковой панели.
